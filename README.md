# Antiquar

Antiquar is a Phoenix project. I want to create and manage a collection of asian art paintings and sketches. The source and material for the collection can be in PDF files, as images in a directory or behind an external URL. The interface should make easy to find paintings or sketches through a smart tagging system. The tagging 
happens manually and saved into database. 
For example, if I want to find Landscape paintings of Yun Shouping, I would select "Landscape" category and "Yun Shouping" as artist, which fetch the names and big thumbnails of the works of "Yun Shouping".
If I want to see the Gongbi Sketches that contain morning glories, then 
that should be easily specified.

To start your Phoenix server:

* Run `mix setup` to install and setup dependencies
* Start Phoenix endpoint with `mix phx.server` or inside IEx with `iex -S mix phx.server`

Now you can visit [`localhost:4000`](http://localhost:4000) from your browser.
